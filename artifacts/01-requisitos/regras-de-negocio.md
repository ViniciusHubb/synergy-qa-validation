# Regras de Negócio

| ID | Regra |
|---|---|
| RN001 | Cada usuário deve possuir um perfil de acesso compatível com sua função: Startup, Investidor Anjo, Profissional ou Administrador. |
| RN002 | Apenas usuários autenticados podem acessar funcionalidades protegidas. |
| RN003 | Apenas o Administrador pode criar e gerenciar eventos da plataforma. |
| RN004 | O Investidor Anjo pode sinalizar publicamente presença em eventos. |
| RN005 | A capacidade máxima de um evento não pode ser ultrapassada. |
| RN006 | Usuários Premium possuem prioridade de inscrição dentro da janela configurada. |
| RN007 | Apenas a Startup proprietária pode gerenciar suas vagas, respeitadas as permissões do sistema. |
| RN008 | Comunidade, roadmap e templates de landing page exigem plano Premium. |
| RN009 | O upgrade Premium do MVP é simulado; pagamento real está fora do escopo. |
| RN010 | O backlog não deve ser tratado como funcionalidade entregue no MVP. |
