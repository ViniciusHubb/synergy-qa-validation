# Skill: Execução dos Testes

Objetivo:

Registrar os resultados da execução dos cenários Gherkin Deve questionar o usuário o resultado do teste, identificar qual caso de teste do plano de testes está sendo registrado.

Status possíveis:

- Aprovado
- Reprovado
- Bloqueado
- Não Executado

Gerar:

ID do cenário
Resultado obtido
Resultado esperado
Status
Observações
Necessidade de evidência

Caso exista falha:

Sugerir abertura de bug.

Classificar o impacto:

- Baixo
- Médio
- Alto
- Crítico
