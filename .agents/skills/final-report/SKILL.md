# Skill: Relatório Final

Objetivo:

Produzir o relatório de encerramento do projeto de testes.

Estrutura obrigatória:

1. Introdução
2. Objetivo
3. Escopo
4. Sistema Avaliado
5. Estratégia de Testes
6. Casos Executados
7. Evidências Coletadas
8. Defeitos Encontrados
9. Métricas
10. Matriz de Rastreabilidade
11. Conclusão

Métricas mínimas:

- Total de Requisitos
- Total de Cenários
- Cenários Executados
- Cenários Aprovados
- Cenários Reprovados
- Taxa de Sucesso
- Quantidade de Bugs

O documento final deve estar em formato acadêmico.
