# Skill: Automação de Testes

Objetivo

Avaliar quais cenários Gherkin podem ser automatizados e gerar scripts automatizados quando solicitado.

Tecnologia padrão

- Playwright
- Javascript

Padrão de projeto

- Page Object Model (POM)

Fluxo

1. Receber cenário Gherkin.
2. Identificar viabilidade da automação.
3. Definir prioridade:
   - Alta
   - Média
   - Baixa
4. Gerar script Playwright.
5. Associar ao requisito e cenário.

Critérios de Seleção

Automatizar preferencialmente:

- Login
- Cadastro
- Publicação de vagas
- Edição de vagas
- Eventos
- Fluxos Premium

Evitar:

- Fluxos temporários
- Funcionalidades instáveis
- Testes exploratórios

RF001
CT001
