# Skill: Matriz de Rastreabilidade

Objetivo:

Garantir cobertura completa dos requisitos.

Gerar:

| Requisito | Cenário | Evidência | Bug |
|-----------|----------|------------|------|

Validar:

- Requisitos sem cenários
- Cenários sem requisitos
- Bugs sem requisito
- Bugs sem cenário

Calcular:

Cobertura (%) dos requisitos.

Fórmula:

(Requisitos cobertos / Total de requisitos) x 100
