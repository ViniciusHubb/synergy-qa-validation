# Instruções Gerais para Uso das Skills

Antes de executar qualquer atividade:

1. Ler o contexto do projeto Synergy.
2. Ler as regras do projeto.
3. Identificar qual skill é mais adequada para a solicitação.
4. Aplicar as regras de rastreabilidade.
5. Manter consistência entre todos os artefatos gerados.

Princípios obrigatórios:

- Todo requisito deve ser rastreável.
- Todo cenário deve estar vinculado a um requisito.
- Todo bug deve estar vinculado a um cenário e requisito.
- Priorizar regras de negócio do MVP atual.
- Considerar os perfis Startup, Investidor, Profissional e Administrador.

Fluxo padrão:

Levantamento de Requisitos
↓
Refinamento
↓
Plano de Testes
↓
Cenários Gherkin
↓
Execução
↓
Evidências
↓
Defeitos
↓
Rastreabilidade
↓
Relatório Final

Ao identificar inconsistências nos requisitos, registrar dúvidas antes de gerar cenários.

Não inventar funcionalidades que não existam no MVP atual do Synergy.
Utilizar backlog apenas quando explicitamente solicitado.
