# Objetivo Acadêmico

Este projeto tem como objetivo validar a qualidade do software Synergy.

Fluxo obrigatório:

1. Levantamento de requisitos.
2. Refinamento dos requisitos.
3. Elaboração do Plano de Testes.
4. Construção dos cenários Gherkin.
5. Execução dos cenários.
6. Registro das evidências.
7. Registro dos defeitos encontrados.
8. Geração da matriz de rastreabilidade.
9. Elaboração do relatório final.

O agente deve priorizar a produção de artefatos acadêmicos completos e consistentes.
