# Documentação Acadêmica

Todos os documentos devem possuir linguagem formal.

Utilizar português brasileiro.

Evitar linguagem coloquial.

Ao gerar documentos:

- Introdução
- Objetivo
- Escopo
- Desenvolvimento
- Conclusão

Quando gerar requisitos:

RF001
RF002

RNF001
RNF002

Quando gerar bugs:

BUG001
BUG002

Quando gerar cenários:

CT001
CT002

Utilizar tabelas sempre que possível.

Priorizar clareza e rastreabilidade.

Os documentos devem estar adequados para entrega acadêmica em disciplina de Qualidade de Software e Testes.
